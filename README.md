# Adnan Khan · Operations Research portfolio

**Live site:** [adnan-khan-or.github.io](https://adnan-khan-or.github.io) · **CV:** [Adnan-Khan-CV.pdf](Adnan-Khan-CV.pdf)

I am a master's student in Operations Research and Risk Analytics at CentraleSupélec, Université Paris-Saclay, with a bachelor's in Industrial and Production Engineering. I build optimisation models for decisions under uncertainty, from two-stage stochastic programmes with CVaR to routing, maintenance and capacity planning, in Python with Gurobi, HiGHS and Pyomo. This repository holds my portfolio site and the reports and notebooks behind it.

## How the site is built

Plain HTML pages with one shared stylesheet, `style.css`. There is no framework and no build step. To change a page, edit its `.html` file and upload it. GitHub Pages publishes the `main` branch within a few minutes.
